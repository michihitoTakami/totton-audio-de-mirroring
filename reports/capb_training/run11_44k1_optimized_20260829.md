# 44.1 kHz CAPB data optimization and checkpoint selection

## Decision

`data/checkpoints/capb/run11_44k1_optimized_20260829/capb_best.pt` is the
selected 44.1→88.2 kHz checkpoint. It passes every unchanged v4 canonical and
held-out gate, plus the additional 64 controller-phase and 64 Hann-OLA
boundary-offset pre-echo sweep. Together with the rechecked 48 kHz run10
checkpoint, both supported rate families now pass G1–G9.

## Data audit and root cause

The run9-era 10,000-example distribution requested 525 isolated clicks and
949 tone bursts, but random 250 ms cropping retained an event in only 154 and
276 examples respectively. Therefore 1,044 nominal transient examples were
eventless. The distribution also contained no direct SMPTE/CCIF two-tone
family. More importantly, the old transient teacher was synthesized at the
target rate and brickwall-filtered before decimation. A nominal click became
a long band-limited pulse at the controller input, unlike the frozen G2b probe
which is a single source-rate sample.

The optimized data path places all 500 clicks and all 949 tone bursts inside
the selected chunk with 5 ms context. It generates these events at 44.1 kHz,
then uses real-FFT zero padding to create a strictly band-limited 88.2 kHz
teacher while preserving `source == target[::2]` exactly. Of the 1,449 focused
examples, 1,044 (72.05%) are clean and 405 are augmented. The distribution now
also contains 525 `imd_two_tone` examples. Across the audited samples, maximum
decimation error remained zero and worst sampled teacher image leakage was
−129.55 dB.

Full machine-readable audits are in
`reports/capb_data_audit/44k1_before_run9/` and
`reports/capb_data_audit/44k1_optimized/`.

## Training constraints

- The exact G2b 0.5–4.0 ms pre-event window supervises energy above the gentle
  prototype on focused transients.
- Procedural edge labels route click/square/step edges toward `gentle`, while
  stationary non-edge examples route toward `sharp`.
- Stationary modulation loss compares the time-varying output with its
  time-mean fixed blend and directly penalizes blend-weight deviation from
  that mean. The direct term closes the weak-gradient region that produced
  SMPTE sidebands while prototype outputs were locally similar.
- These are training-only constraints. No runtime guard, hard 20 kHz split,
  prototype coefficient change, or generated high-frequency target was added.

The selected artifact includes `capb_pre_polish.pt`; the final deterministic
margin epoch is configured by
`configs/training_stage1_capb_44k1_margin.yaml`. The JSON training history
records the full effective data/training configuration and configuration
hashes.

## Selection evidence

| Candidate | G2b impulse | G5 impulse train | G9 SMPTE | Decision |
|---|---:|---:|---:|---|
| run9 retrain | fail | fail | −87 dB class | reject |
| transient warm-up epoch 20 | 1.77e−9 | 0.484 dB | −85.01 dB | reject G9 |
| stationary output polish | 4.70e−9 | 0.480 dB | −94.18 dB | reject G9 |
| direct weight polish epoch 4 | 2.53e−7 | pass | −125.8 dB | reject G2b |
| over-strong transient polish | 5.01e−15 | 0.497 dB | −125.1 dB | reject narrow G5 margin |
| selected margin polish | 1.05e−7 | 0.446 dB | −125.6 dB | accept |

The rejected over-strong candidate demonstrates why passing alone was not
used for selection: its impulse-train gain margin was only about 0.003 dB.

## Final evaluation

- 44.1 kHz v4 canonical + held-out G1–G9: **PASS**
- 44.1 kHz 64 controller phases: **PASS**, worst margin −2.84 dB
- 44.1 kHz 64 OLA boundary offsets: **PASS**, worst margin −2.91 dB
- 44.1 kHz THD / SMPTE IMD / CCIF IMD: −145.5 / −125.6 / −153.6 dB
- 48 kHz v4 canonical + held-out G1–G9 recheck: **PASS**
- 48 kHz SMPTE IMD: −141.43 dB
